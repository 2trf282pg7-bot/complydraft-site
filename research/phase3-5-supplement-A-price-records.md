# 工程③.5 補完A — 公開DB・遮断サイトの価格実数収集（実施記録）

- 実施日: 2026-08-15
- 実施環境: **リモート実行コンテナ（Claude Code on the web / Cowork系）**。指示書が想定した「ローカルセッション」ではない
- 目的: 価格実数と出典の記録のみ。評価・推薦・優劣判断は一切行わない

## 0. 最重要の前提（本記録の読み方）

### 0-1. 実行環境が指示書の前提と違う

指示書は「Coworkのプロキシ遮断を回避するため、ローカルのClaude Codeセッションで実行」を前提としている。しかし本セッションは**リモートのコンテナ上で動いており、指示書が回避対象としていた egress プロキシの内側にいる**。実測結果:

| 手段 | 結果 |
|---|---|
| `curl https://www.lrm.jp/` | `CONNECT tunnel failed, response 403`（ポリシー拒否） |
| `curl https://secure-navi.jp/` | 同上 403 |
| WebFetch `www.lrm.jp` / `secure-navi.jp` | `EGRESS_BLOCKED` |
| WebFetch `it-shien.smrj.go.jp`（IT導入補助金DB） | `EGRESS_BLOCKED` |
| WebFetch `www.jftc.go.jp`（公取委） | `EGRESS_BLOCKED` |
| WebFetch `www.it-hojo.jp` | `EGRESS_BLOCKED` |
| WebSearch（検索インデックス） | **利用可能** |

プロキシの status エンドポイントにも `connect_rejected / gateway answered 403 to CONNECT (policy denial)` として記録された。README の指示（「403/407 は迂回せず報告する」）に従い、**回避は試みていない**。

**結論: タスク1〜4の中核である「サイトを直接開いて本文から価格を採る」作業は、この環境では1件も実行できていない。** 以下に記録した価格は、すべて**検索エンジン経由の二次的な取得**であり、指示書が求めた一次確認とは別物である。

### 0-2. 数値の信頼性についての明示的な警告

本記録の価格は、検索ツールが返した要約テキストに現れた数値である。要約は小型モデルが生成しており、**桁誤り・プラン取り違え・別サービスの混入の可能性を排除できない**。したがって:

- **ソースランクSは今回ゼロ件**（Sは一次ページ本文を直接取得して確認したものと定義したため）
- 全レコードに「本文未検証」フラグが付く
- **意思決定に使う前に、ネットワーク制限のない環境で出典URLを開いて再確認すること**

### 0-3. ソースランクの定義（本記録での運用）

| ランク | 定義 | 本記録での件数 |
|---|---|---|
| S | 一次情報（事業者公式ページ/公式PDF）の本文を直接取得して確認 | 0件 |
| A | 一次情報（公式サイト・公式リリース・報道）に紐づく数値だが、本文は未取得（検索要約経由） | 5件 |
| B | 比較メディア等の二次情報に載った個社価格（本文未取得） | 6件 |
| C | 個社価格ではない「相場・レンジ」記述、または事業者を特定できなかった価格例 | 12件 |

### 0-4. robots.txt の扱い

指示書は「robots.txtで拒否されたパスはスキップし『robots拒否』と記録」としているが、**robots.txt 自体が取得できない**（同じ egress ポリシーで拒否）。したがって本記録に「robots拒否」判定は1件も存在しない。すべて**「robots未確認・ネットワーク遮断により未到達」**である。両者は原因が異なるので混同しないこと。

### 0-5. 工程②正誤表（本調査でも正として据え置き）

- シート4-1: 書面調査対象は9万名ではなく **11万名以上**（公取委2025-05-12公表）
- シート3B-19: 価格仮説は月額表記（**月112,500〜472,500円**）を正とする

いずれも本セッションでは再確認していない（`jftc.go.jp` が遮断されているため）。工程②時点の確定事項として引き継ぐ。

## 第2層: 取得できた／できなかったの構造メモ

### 2-1. タスク1（IT導入補助金 ITツール登録DB）— **完全未達**

`it-shien.smrj.go.jp` が egress ポリシーで遮断され、ツール詳細ページを1件も開けなかった。検索インデックス経由でツール詳細URL（例: `?it_tool_numbering=DL07-0011305`, `DL06-0013799`）は列挙できたが、**登録価格は本文にしかないため取得できず**。

構造上わかったこと:
- 登録価格は「価格説明資料」として事務局に提出され、カテゴリー1（ソフトウェア）1つあたりの役務価格の妥当性が審査される（登録要領PDF）。つまり**DBの価格は実売価格ではなく「登録価格」であり、そのまま市場価格として扱えない**
- CL-19（警備）に該当する登録ツールは、検索インデックスからは特定できなかった。警備業向けの価格実数は結局、**ベンダー公式・比較メディア経由（レコード1〜4）でしか取れていない**
- CL-04/CL-03 では、SecureNavi と スリーエーコンサルティング「アシスト」シリーズ（ISMS/Pマーク/9001/14001）が補助金対象ツールに認定されていることのみ確認。**登録価格は未取得**

### 2-2. タスク2（遮断サイトの直接取得）— **直接取得は全件未達**

指示書に挙がった11系統すべてで、直接取得は0件。検索経由で数値が拾えたのは、セキュリオ（旧価格のみ）、SecureNavi、カンサポ、AIPPAY、日本アイアール、日立SBOM（管理サービスのみ）の6系統。マモリス、pmark-assist、IPCC、isoprocess/isoken/isotracker、CMP代行18社は数値ゼロ。
